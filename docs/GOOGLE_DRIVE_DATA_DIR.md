# プロファイルを Google ドライブで共有する（個人・会社アカウント）

自動 UPLOAD の **設定・プロファイル（SQLite）** は既定では:

`%LOCALAPPDATA%\FTPAutoSync\profiles.db`

このフォルダ全体を **Google ドライブ上の同期フォルダ**に置き換えると、同じ設定ファイルを複数 PC で共有したり、**別の Google アカウントにコピー**して使えます。

## 1. 環境変数 `FTP_AUTOSYNC_DATA_DIR`

保存先の **親ディレクトリ**を指定します（アプリがその下に `profiles.db` などを作成します）。

### Windows（コマンドプロンプト・そのセッションだけ）

```bat
set FTP_AUTOSYNC_DATA_DIR=G:\マイドライブ\FTPAutoSyncData
python app.py
```

### Windows（ユーザー環境変数に永続）

1. 「環境変数」→ユーザー環境変数に新規  
   - 名前: `FTP_AUTOSYNC_DATA_DIR`  
   - 値: 例 `G:\マイドライブ\FTPAutoSyncData`  
2. **Google ドライブ for Desktop** で同期されるフォルダ内のパスにする（下記）。

### パスの例（パソコンや言語で名前が違います）

| よくある場所 | 例 |
|--------------|-----|
| 英語 UI | `G:\My Drive\FTPAutoSyncData` |
| 日本語 UI | `G:\マイドライブ\FTPAutoSyncData` |
| 会社の共有ドライブ | ドライブ文字は環境ごとに異なる |

**固定のドライブ文字に依存しない**場合: エクスプローラで Google ドライブのフォルダを開き、アドレスバーをコピーして環境変数に貼る。

## 2. 起動用バッチの例（任意）

リポジトリ内の `scripts/run_with_data_dir.template.bat` をコピーして、パスだけ編集して使えます。

## 3. 他の Google アカウントへ「コピー」する

1. エクスプローラまたは [drive.google.com](https://drive.google.com) で、`FTPAutoSyncData` フォルダ（中身ごと）を  
   - **共有リンク**で渡す、または  
   - 別アカウントのマイドライブに **フォルダごとアップロード／複製**  
2. もう一方の PC でも **同じ相対パス**になるように置くか、その PC の実パスを `FTP_AUTOSYNC_DATA_DIR` に設定する。

Google ドライブが同期できれば、**別アカウントでも同じプロファイル DB を参照**できます。

## 4. セキュリティ（重要）

- `profiles.db` には **FTP パスワードなどが含まれる**ことがあります。  
- 共有フォルダ・共有ドライブを使う場合は **閲覧権限**を最小限にしてください。  
- 公開リポジトリに DB をコミットしないでください。

## 5. トラブル

- **Google ドライブの同期が追いつく前に**アプリを開くと、DB が古い／ロックされることがあります。同期完了後に起動してください。  
- 複数 PC で **同時に GUI を開いて保存**すると SQLite で競合します。**一人ずつ保存**する運用を推奨します。
